# Todo CLI

A single-user command-line todo list application for tracking tasks, optionally with due dates.

## Language

**Due Date**:
An optional calendar date (no time-of-day) indicating when a task should be completed by.
_Avoid_: Deadline, due time

**Overdue**:
A task whose due date is earlier than today and which is not yet marked done.
_Avoid_: Late, expired
